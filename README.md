# Знахідка — електронне бюро знахідок

Кросплатформний застосунок на Flutter (лабораторна робота №3, дисципліна «Кросплатформне програмування»).

Реалізовано екрани без бізнес-логіки (дані — hardcoded):

- вхід, реєстрація, відновлення пароля через електронну пошту;
- головна сторінка зі стрічкою оголошень і швидким доступом до функцій;
- профіль користувача зі зміною пароля.

## Запуск

```bash
flutter pub get
flutter run -d macos   # або -d chrome / -d windows
```

## Структура

```
lib/
├── main.dart
├── app.dart
├── core/
│   ├── data/          # hardcoded-дані (MockData)
│   ├── models/        # моделі (LostItem)
│   ├── navigation/    # маршрути (AppRoutes)
│   ├── theme/         # кольори, відступи, тема
│   └── widgets/       # повторно використовувані віджети
└── features/
    ├── auth/          # вхід, реєстрація, відновлення пароля
    ├── home/          # головна сторінка
    ├── placeholder/   # заглушки для наступних лабораторних
    ├── profile/       # профіль і зміна пароля
    └── shell/         # каркас із бічною навігацією
```
